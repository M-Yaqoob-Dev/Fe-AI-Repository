# FE AI Engineering Track Guidelines

## Tech Stack
- Node.js (LTS)
- React with TypeScript
- Git & GitHub
- Cursor IDE / Claude Code

## Prompting Guidelines
- Always provide structured prompts with specific framework/library requirements (e.g., Zod, React Hook Form).
- Include explicit accessibility requirements (semantic labels, ARIA attributes).
- Request automated verification (React Testing Library tests) in initial instructions.

## Commit Conventions
We follow the Conventional Commits specification (v1.0.0):
- `feat:` A new feature
- `fix:` A bug fix
- `docs:` Documentation changes
- `chore:` Maintenance tasks, dependency updates, or tool configurations
